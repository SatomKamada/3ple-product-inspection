# 商品横断検索 モック

商品・商品属性情報・商品規格を横断して検索し、結果をタブで切り替えて表示するモックです。
ビルド不要の静的ファイル（HTML / CSS / JavaScript）のみで動きます。

## 構成

```
.
├── .devcontainer/devcontainer.json  # Codespaces 起動時にサーバーを自動起動
├── index.html                       # 画面
├── css/style.css                    # スタイル
└── js/
    ├── data.js                      # モックデータ（固定シードで自動生成）
    └── app.js                       # 検索・一覧表示・タブ・ページングなど
```

## Codespaces での起動

1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてコミット
2. リポジトリの「Code」→「Codespaces」→「Create codespace on main」
3. 起動すると `python3 -m http.server 8000` が自動で走り、ポート 8000 がブラウザで開きます

自動で開かない場合はターミナルで次を実行し、「ポート」タブから 8000 を開いてください。

```
python3 -m http.server 8000
```

## 検索の仕様（モック）

| 検索項目 | 対象 |
|---|---|
| 商品名 / 商品コード / JANコード / 公開状態（商品） / 更新日時（商品） | 商品 |
| 掲載履歴コード / 業態区分 / 掲載日時 | 商品属性情報 |
| 商品規格コード / ちょっぷル種別 / 規格区分 / 販売形態 / 在庫 / 本店公開状態 / 更新日時（商品規格） | 商品規格 |

- 商品の条件を満たし、かつ（属性の条件があれば）一致する属性を1件以上、（規格の条件があれば）一致する規格を1件以上持つ商品がヒットします
- 各タブには、ヒットした商品に紐づく属性・規格がすべて表示され、条件に直接一致した行には「一致」バッジが付きます
- 「条件に一致した属性・規格のみ表示」をオンにすると、一致した行だけに絞れます
- 商品名のリンク、または商品タブの「属性 n件 / 規格 n件」ボタンで、その商品に紐づく情報だけに絞り込めます
- テキスト項目は部分一致です

## カスタマイズのポイント

- 選択肢（業態区分・ちょっぷル種別など）: `js/data.js` の `MASTER`
- 一覧の列: `js/app.js` の `COLUMNS`
- 検索項目と対象データの対応: `js/app.js` の `COND_DEFS` と `matchProduct / matchAttribute / matchVariant`
- ヘッダー色: `css/style.css` の `--hdr-products / --hdr-attributes / --hdr-variants`
